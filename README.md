# HealthConnect

HealthConnect is a comprehensive healthcare application connecting users with doctors for consultations, symptom checking, and health tips.

## Download the App

The HealthConnect application is distributed as an Android APK.

📥 **[Download Latest APK from GitHub Releases](https://github.com/Ehtheshaam/Updated-health-connect/releases)** *(Placeholder Link)*

### Installation Instructions:
1. Download the `.apk` file to your Android device.
2. When you open the file, your device may warn you about installing unknown apps.
3. Go to your device **Settings** > **Apps** > **Special app access** > **Install unknown apps** (or similar, depending on your Android version) and allow the source you downloaded the file from (e.g., your browser or file manager).
4. Tap the downloaded `.apk` file again to complete the installation.

## Running Locally

To run the app locally for development using Expo Go:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Expo development server:
   ```bash
   npx expo start
   ```
3. Scan the generated QR code using the Expo Go app on your mobile device.
